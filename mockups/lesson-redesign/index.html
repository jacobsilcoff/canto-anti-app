Proposal · Lesson redesign

Bite-sized steps, real goals, and a lesson that teaches as you go

Six tappable mockups for reorganizing the AI Learning Path. The core moves: a lesson becomes 2–4 short steps (teach a little → drill it immediately) instead of a teach-wall followed by 15 drills; the AI construction drill becomes its own “AI Speak” step; and between lessons, daily quests, a friends league and unit checkpoints give XP something to push against. Full audit + implementation plan: docs/LESSON_REDESIGN.md in the repo. Toggle dark mode (top right).

The twelve moves, by phase

Phase 1

Lessons become steps

Author 2–4 micro-steps (0–2 teach blocks + 3–5 drills each) instead of teach-wall + 7–14 drills. The player already supports multi-segment lessons — this is mostly a prompt/assembler change.

Phase 1

Teach cards + quick checks

One block per screen with an ungraded one-tap check every card or two. You never read more than ~2 cards without doing something.

Phase 1

Warm-up recall opener

The 2 interleaved review drills move to the front as a labeled warm-up — retrieval practice before new input, and a gentler on-ramp.

Phase 1

AI Speak as a step

Construction drill = its own named final step, 3 turns, skippable. Billed as the lesson's highlight instead of buried at the point of maximum fatigue.

Phase 2

Daily quests + chest

3 rotating quests computable from events we already track (XP, combo, drill types, card adds). All 3 done → chest with bonus XP, occasionally a streak freeze.

Phase 2

Unit checkpoints

Deterministic quiz from stored drills when a chapter closes. Bonus XP, a shield on the banner, mastery-ledger bumps — zero LLM cost.

Phase 2

Adjustable daily goal

Replace the fixed 50-XP goal with Casual/Regular/Serious/Intense. The ring and quests read it automatically.

Phase 2

Recap on results

The lesson's key table or top examples repeated on the results screen — free retention from content we already store.

Phase 3

Friends weekly league

Weekly XP ranking among accepted friends — one query over the existing points ledger, no new tables. The app's social edge over solo Duolingo clones.

Phase 3

Lesson length setting

Quick (~4 min) / Standard / Thorough (~12 min) — a generation-time knob in Settings and on the intro sheet.

Phase 3

Course focus dial

Balanced / grammar / vocab / conversation preference steering the planner. One prompt line.

Phase 3

Test out

“I know this” → 4 hardest stored drills; pass marks the lesson done at half XP. Respects prior knowledge — a top churn-saver for non-beginners.
